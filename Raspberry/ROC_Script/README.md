# Installing `roc.service` with systemd

This guide explains how to install and enable the ROC startup service using the files stored in:

```text
ROC_Script/
├── roc_start.sh
└── roc.service
```

The installation consists of copying `roc.service` to the systemd service directory and then registering and enabling it with `systemctl`.

## 1. Verify the startup script

Make sure the startup script is executable:

```bash
chmod +x ~/ROC_V2/ROC_Script/roc_start.sh
```

You can verify the permissions with:

```bash
ls -l ~/ROC_V2/ROC_Script/roc_start.sh
```

## 2. Copy the service file to systemd

From the `ROC_Script` directory:

```bash
cd ~/ROC_V2/ROC_Script
```

Copy the service file to the systemd service directory:

```bash
sudo cp roc.service /etc/systemd/system/roc.service
```

Verify that the file was correctly installed:

```bash
ls -l /etc/systemd/system/roc.service
```

You can also inspect its contents with:

```bash
cat /etc/systemd/system/roc.service
```

## 3. Reload systemd

After copying or modifying a service file, reload the systemd configuration:

```bash
sudo systemctl daemon-reload
```

This makes systemd detect the newly installed `roc.service`.

## 4. Enable the ROC service

Enable the service so that it starts automatically during system boot:

```bash
sudo systemctl enable roc.service
```

Verify that the service is enabled:

```bash
systemctl is-enabled roc.service
```

Expected output:

```text
enabled
```

## 5. Start the service

Start the service manually without rebooting the ROC:

```bash
sudo systemctl start roc.service
```

Alternatively, enable and start the service in a single command:

```bash
sudo systemctl enable --now roc.service
```

## 6. Check the service status

Verify that the service was started correctly:

```bash
systemctl status roc.service
```

## 7. Check the service logs

To inspect the logs generated by the service:

```bash
journalctl -u roc.service
```

To show only logs from the current boot:

```bash
journalctl -u roc.service -b
```

To follow the logs in real time:

```bash
journalctl -u roc.service -f
```

## 8. Updating the service

If `roc_start.sh` is modified, restart the service:

```bash
sudo systemctl restart roc.service
```

If `roc.service` is modified inside `ROC_Script`, copy it again:

```bash
cd ~/ROC_V2/ROC_Script

sudo cp roc.service /etc/systemd/system/roc.service
sudo systemctl daemon-reload
sudo systemctl restart roc.service
```

## 9. Stop the service

To manually stop the ROC service:

```bash
sudo systemctl stop roc.service
```

## 10. Disable automatic startup

To prevent the service from starting automatically during boot:

```bash
sudo systemctl disable roc.service
```

To disable and stop it at the same time:

```bash
sudo systemctl disable --now roc.service
```

## Quick installation

For a new installation, the complete procedure is:

```bash
cd ~/ROC_V2/ROC_Script

chmod +x roc_start.sh

sudo cp roc.service /etc/systemd/system/roc.service

sudo systemctl daemon-reload

sudo systemctl enable --now roc.service

systemctl status roc.service
```

The resulting configuration is:

```text
~/ROC_V2/ROC_Script/
├── roc_start.sh
└── roc.service
        │
        │  sudo cp
        ▼
/etc/systemd/system/roc.service
        │
        │  systemctl enable/start
        ▼
systemd
        │
        ▼
~/ROC_V2/ROC_Script/roc_start.sh
```

The `roc.service` file remains versioned inside `ROC_Script`, while `/etc/systemd/system/roc.service` is the installed system copy used by systemd.
